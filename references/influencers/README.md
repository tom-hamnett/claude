# References — Influencers (Narrator Character Sheets)

Each narrator is a folder containing a locked 10-image character sheet:
- `hero.png` — full-body front-facing hero image
- `angle_front_close.png` — close-up face-forward
- `angle_front_medium.png` — medium shot front
- `angle_three_quarter_left.png` — 3/4 view left
- `angle_three_quarter_right.png` — 3/4 view right
- `angle_profile_left.png` — left profile
- `angle_profile_right.png` — right profile
- `angle_looking_up.png` — looking slightly up
- `angle_looking_down.png` — looking slightly down
- `angle_walking.png` — walking/movement shot

All 10 images are generated from the same seed character description and edit chain.
Once locked, these are the **only** images Veo animates from via startFrame.
Never regenerate from text prompts.
