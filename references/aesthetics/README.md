# References — Aesthetics

Style reference folders used to condition Nano Banana 2 image generation.

## Folders

### `ugc-selfie/`
iPhone-style grounded UGC reference images. For the Agitation segment.
Characteristics:
- Natural camera imperfections (slight grain, auto-focus softness)
- iPhone Portrait mode bokeh
- Available light
- Unpolished framing
- Slight vertical tilt
- Skin realism (pores, natural texture)

### `cinematic/`
Hyper-stylised cinematic reference images. For Hook and Bookend segments.
Characteristics:
- Impossible reality (cyber helmets, surreal environments)
- High contrast colour grading
- Rembrandt lighting
- Shallow depth of field (f/1.8)
- Kodak Portra 400 grade
- Documentary polish

### `data-viz/`
Clean data visualisation reference images. For the Pivot segment.
Characteristics:
- Dark background (#0a0a0f)
- Purple (#6c63ff) and gold (#ffd166) accents
- Minimal typography (Playfair Display)
- Non-3D charts (the flashy BI dashboard look is forbidden)
- Animated numbers, rapid metric reveals
- Clean UI highlights
